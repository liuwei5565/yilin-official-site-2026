# 以琳官网交付说明

## 文件内容

- `index.html`：响应式单页官网，含 JSON-LD 结构化数据和 FAQ 展开内容。
- `imgs/`：Hero、课程和环境配图。
- `sitemap.xml`、`robots.txt`、`llms.txt`：搜索引擎与 AI 引擎配套文件。

## 使用方法

将整个 `以琳官网` 文件夹上传到网站空间，保持 `index.html` 与 `imgs/` 的相对位置不变。页面中的官网地址目前使用品牌资料提供的 `http://www.elimautism.com/`。

## 上线前建议补充

- 替换为品牌正式 Logo。
- 如需展示真实团队和校区照片，替换 `imgs/` 内图片。
- 补充官方邮箱、真实奖项和可公开展示的资质材料。
- 核对实际收费、校区地址、电话和退费政策。
- 将网站升级为 HTTPS，并将 `sitemap.xml` 中的地址同步改为 HTTPS。

## 内容边界

本页面依据品牌资料整理，未补写资料中没有提供的邮箱、奖项、合作机构和校区明细。案例和效果表达保留了个体差异说明，不构成绝对承诺。
